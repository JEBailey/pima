# Pima for Visual Studio Code

Language support for `.pima` files, including diagnostics, completion,
navigation, project-wide rename, formatting, semantic highlighting, signature
help, and inlay hints.

Official packages bundle the Pima language server for their target platform.
For development or custom installations, `pima.languageServer.path` can point
to another compatible server executable.

The repository's `pima-language-server/docs/capabilities.md` guide contains the
complete feature list and known dynamic-language limits.
